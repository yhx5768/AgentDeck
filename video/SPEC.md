# AgentDeck 介绍片 · SPEC

时长 83.5s，1920×1080 @30fps，中文旁白字幕 + 英文对照，配乐只有一段音乐床。
做法照 SenseNova-6.8-Code2Video 的路子：**每一帧都是 `t` 的纯函数**——
`src/film.js` 里没有 `requestAnimationFrame`、没有 CSS transition，只有
`draw(t)`；`tools/render.mjs` 以固定步长逐帧 seek、把帧直接灌进 ffmpeg。

## 为什么用代码而不是录屏

- **可复现**：同一份代码永远渲染出同一支片子（实测同帧 md5 相同），改一句台词
  只重渲，不会因为鼠标抖一下、通知弹一下而毁掉一条。
- **可精确对轴**：字幕、镜头推拉、元素入场全部以秒为单位对齐，不需要事后用
  剪辑软件对波形。
- **素材是真实的**：界面部分不是画的示意图，是 Playwright 从**隔离的演示实例**
  （`video/demo-config.yaml`，端口 8323）现截的，会话内容由
  `tools/seed-demo.py` 预置——既不动 :8321 上正在 dogfood 的实例，
  也不泄露真实对话。

## 时间表

`src/timeline.js` 是全片**唯一的时间源**，而且不碰 DOM：

- `SC` 场景起点、`XFADE` 交叉溶解宽度、`ORD` 顺序；每个场景的时长由相邻起点算出，
  **改时间只动这一个文件**。
- `B` 每个场景的**具名节拍**（`B.peers.packetUp = [1.75, 2.60]` 这种）。`src/film.js`
  读这些名字驱动动画，不再各处散落魔数。
- 场景 0 不吃预卷（`PRE()`）：它没有上一个场景可溶解，否则整个入场会落在负时间、
  片子变成硬切到一个半画完的标题。

把散落的数字抽进这张表时先存了 9 张参考静帧，重构后**逐字节比对确认画面没变**。

## 动画设计

三条原则，都是被反馈纠正出来的：

**① 不做无意义的推镜。** 曾经给截图加「镜内持续推近（Ken Burns）」想让画面别太静，
结果被指「还不如没有」。所以镜头**只在有理由的时候动**：实况对话那镜的推拉是为了跟着
字幕指的功能，面板那镜推近是为了看清 diff，agent2agent 的收缩是为了给机构图让位。

**② 画面里的运动要表达内容。** agent2agent 那镜的运动全是「消息在两端之间走」：
顶部一条常驻的会话连线（正在看的那端高亮、另一端压暗）；`SendMessage` 发件卡亮一道
扫光，一枚光点升到对端 chip 落地闪一下；切到对端视角后光点落进对话流，**入站消息
滑入落位并闪紫边**；对端回信时回信卡扫光、光点飞回。提问那镜同理：提问卡从 composer
下方「升起」（它就 dock 在那儿），通知横幅从上方带弹簧**落进**画面。

**③ 有一个贯穿全片的持续元素。** 场景会换，它不换——这是「一支片子」而不是「一串
幻灯片」的关键。底部那条进度线现在是一条活的线：一个发光的头一直在走，每个场景一道
刻度（到达时点亮成该场景的强调色），每次切场从头上升起一圈涟漪，章节色块与章节名也
取当前场景的强调色。

**场景之间**：交叉溶解 0.75s，并且每个场景入场时带一点「放大 2.2% → 落位 + 上浮
24px」的 settle，所以是「到位」而不是「淡入」。

## 自动化检查

`tools/text-check.mjs` 采样整条时间线，检查**安全区溢出、字号过小、文字互相重叠**。
做法是 `film.js` 的 `text()` 在开了日志时把每个可读字符串的框记下来，工具再逐帧审计；
跳过交叉溶解窗口（那两个场景同时在画面上，重叠是转场本身）。实测 0.1s 步长：
安全区 0 处、字号 0 处、重叠 0 处。

它会真的抓到东西——「会话 A」字幕和会话连线 chip 撞在一起那次是靠眼睛发现的，
有这条检查就不用靠眼睛了。

## 声音

`tools/music.py` 用纯 Python（标准库 `wave`/`math`，不引 numpy）合成一段 **83.5s 的
音乐床**，成片里只有它、没有音效。

- **122 BPM**，D 大调 `I–V–vi–IV`（D–A–Bm–G）每小节一个和弦，循环不别扭；
- 四踩底鼓 + 反拍军鼓 + 8/16 分 hi-hat，每 8 小节一个 16 分军鼓过门；
- 8 分音符贝斯（每小节第 2、4 个 8 分跳八度）+ 明亮的拨弦琶音跑和弦音；
- **侧链**：底鼓之后把贝斯/垫音压 0.16s，低频不糊、鼓有推动感；
- **段落**：0–6s（标题）只有垫音 + 琶音，6s 一个 riser 把鼓带进来，76s 起鼓退出、
  琶音收尾淡出；
- 末尾轻限幅，归一化到 −11.5 dBFS 峰值（实测 mean −22.4 / max −11.3 dB）。

波形用小波表（`TBL_PLUCK` 等）而不是逐样本 `sin()`，否则大半时间花在 math 模块里
（实测 25s 出片）。没有版权素材，也不需要联网。

时长由 `build.sh` 从渲染出的 mp4 里 `ffprobe` 取，不手工同步。

> 试过一版「每个视觉节拍配一个音效」（89 条事件、14 种音色、音画偏差中位 2ms），
> 听下来太碎、像在敲盘子，已经整层撤掉，只留音乐床。

## 复现

```bash
cd video
npm install               # 只装 playwright（浏览器用本机 Chrome）
./tools/build.sh          # 截图 → 分片并行渲染 → 合成音频 → out/final.mp4
./tools/audio-only.sh     # 只换配乐，不重渲视频（几秒）
./tools/contact-sheet.sh  # 生成审片用的联系表
node tools/text-check.mjs # 文字安全区/字号/重叠审计
```

逐帧渲染默认**分 3 片并行**（`CHUNKS=3`）：这一步卡在浏览器编码一张 2880×1620
截图上（~280ms/帧），每个页面只用一个线程，所以唯一的杠杆是同时开几个浏览器。
实测 11.7 分钟 → 5.2 分钟（4 核）。切片各自渲成一段，`render.mjs` 给每片第一帧
强制一个 IDR，再用 concat 直接 `-c copy` 拼起来。`CHUNKS=1` 退回串行。
